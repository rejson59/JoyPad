# JoyPad v1.6 / PR #16

v1.6 jest aktualizacją wspólnego ekranu i telefonu-pada. Najważniejsze kryterium pozostaje bez zmian: bezpośredni WebRTC, szybkie wejście i brak odczuwalnego laga. Relay MQTT jest wyłącznie ścieżką awaryjną.

## Co weszło

- **Protokół i pokój:** QR przenosi kod oraz jednorazowy klucz handshake. Do QR kopiowany jest tylko bezpieczny parametr `srv`; credentiale TURN i sekrety URL pozostają poza linkiem. Wiadomości wejściowe mają lekki runtime guard, a host odrzuca zalew pakietów przed silnikiem bez ciężkiej kryptografii na każdej klatce. Token i walidacja działają przy dołączaniu, nie w pętli wejścia.
- **Wężowy Wir:** dostępna nowa gra multiplayer, wyraźnie oznaczona `NOWOŚĆ · BETA`. Canvas/WebGL korzystają ze wspólnego kontraktu rundy, a telefon ma osobny D-pad z czterema kierunkami i przytrzymywanym sprintem. Utrata fokusu, obrót lub opuszczenie rundy zerują wejście.
- **Moments:** automatyczny wybór interesujących akcji z ostatniej rundy pozostaje w tle. Na wynikach jest przycisk `Save to Moments Gallery`; dopiero jego kliknięcie kopiuje Blob i metadane do lokalnego IndexedDB. Nie ma automatycznego trwałego zapisu, uploadu ani konta online. Galeria pozwala odtworzyć, pobrać i usunąć klip.
- **Profil telefonu:** profil ma stabilny, lokalny identyfikator, awatar, motyw i lokalny postęp: rozegrane rundy, wygrane, serie i osiągnięcia. Po ponownym użyciu tego samego kontrolera dane wracają z jego localStorage. Do telewizora trafia tylko walidowany snapshot potrzebny do rosteru i podglądu.
- **Turniej i 2v2:** menu ustawień ma format `ZWYKŁA RUNDA`, `TURNIEJ` oraz `2V2 / DRUŻYNY`. Tryb turniejowy prowadzi lokalny licznik meczu 1/3–3/3, a kontrakt sesji przenosi format i numer rundy. `Turbo League` ma istniejący podział drużyn; ta wersja zaczyna ujednolicanie formatu bez zmiany zachowania zwykłego FFA.
- **Co nowego?:** biblioteka ma okno update notes dla v1.6 i następnego kroku v1.7. Nie otwiera się automatycznie nad rozgrywką i nie blokuje startu.
- **Wielojęzyczność:** teksty nowych modułów są trzymane w komponentach i nie zależą od danych sieciowych; nazwa funkcji `Moments` pozostaje angielska. Kolejny krok może podłączyć katalog tłumaczeń bez zmiany kontraktu gry.

## Czego nie robimy w v1.6

Nie rozwijamy rotacji gier, spectator mode, quick game ani PWA/offline. Relay, lokalne storage i IndexedDB mają bezpieczne ścieżki fallback — ich brak nie blokuje zwykłej gry.

## Testy

Przed PR uruchomiono:

```bash
npm run build
npm run lint
npm run selftest:platform
npm run selftest:console
npm run selftest:arcade
npm run selftest:relay
npm run selftest:replay
npm run selftest:v16
```

`npm run test:replay` jest skonfigurowany i został uruchomiony, ale w środowisku bez pobranego Chromium Playwright zgłosił brak executable. Próba `npx playwright install chromium` zakończyła się błędem sieciowym `ECONNRESET`; testy UI wymagają uruchomienia w CI lub środowisku z cache przeglądarki.
